# مدرسة شمس الخير للقرآن الكريم — Shams Alkhair

هذا هو المستودع العام المخصص لمشروع **مدرسة شمس الخير للقرآن الكريم**.

> **حالة النشر:** إعداد المستودع العام تم. **ملفات التطبيق الكاملة لم تُرفع بعد**؛ النسخة المصدرية موجودة في حزمة الإصدار `v6.3` التي جرى إعدادها واختبار سلامة محتواها محليًا. لا تعتبر روابط المعاينة السابقة موقعًا إنتاجيًا.

## التقنية

Next.js 16 · React 19 · TypeScript · Prisma 6 · PostgreSQL 17 · Arabic RTL.

## المراحل المخططة والمنفذة مبدئيًا

1. الموقع العام والتسجيل وحجز اختبار تحديد المستوى.
2. حسابات الإدارة والمعلمين والطلاب، والحضور عبر QR.
3. لوحة ولي الأمر والتقارير والمتابعة الأكاديمية.
4. التسميع الصوتي بمراجعة المعلم.
5. مكتبة الفيديوهات التعليمية.
6. الرسوم والشهادات والاختبارات والجداول والإحصاءات.

هذه الميزات مكتوبة في نسخة التطوير، لكن **لا يجوز استخدام بيانات الطلاب الحقيقية قبل نجاح البناء واختبارات قاعدة البيانات والصلاحيات واختبار الخصوصية**.

## إدراج النسخة المصدرية

عند استخراج حزمة المصدر `shams-alkhair-v6.3-private-release.zip`، انسخ **محتويات المجلد الداخلي `shams-alkhair/`** إلى جذر المستودع، دون إضافة ملفات `.env` أو التسجيلات والنسخ الاحتياطية. يجب إجراء مراجعة أمنية قبل أي نشر إنتاجي.

الاختبارات التي تم تشغيلها محليًا: **82/82** من فحوص المنطق والبنية؛ اختبارات `npm install` و`next build` والتكامل الفعلي مع PostgreSQL لم تكتمل بعد.

## الأمان

- لا ترفع كلمات مرور أو مفاتيح API أو ملفات تسجيل الطلاب أو الأصوات.
- احتفظ بملفات `.env` في بيئة التشغيل فقط.
- ينبغي منح كل قسم صلاحيات وصول معزولة على مستوى قاعدة البيانات.

**تاريخ إنشاء المستودع العام:** أكتوبر 2026.
